## 回答组织

重写 45 条既有主回答，重点覆盖 JavaScript 核心、项目指标、迁移与上传、面试表达，以及部分过短场景答案。新增题主回答控制在 100～260 字符，按结论、机制、场景与适用条件连贯表达；简单计算与单一追问按信息需求保持简洁。

主回答默认显示，原理、例子、实现代码、适用条件、追问和资料按需展开。删除主回答中的个人负责范围免责式提醒，项目案例明确写为参考或假设。技术限制继续通过具体条件解释，例如超时后可能已执行、共享缓存的权限陈旧窗口，以及 Promise 组合不会取消底层工作。

新内容涉及版本与安全机制的部分已查阅 Vue、React、Node.js、Redis、MDN 和 OWASP 文档；相应题目附可核对链接。现有代码示例与来源保留。
