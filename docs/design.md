# 设计说明

## 设计方向

知序面向需要持续复习和练习表达的前端工程师。首页以「今天练什么、接着哪里练、哪些地方仍不熟」为主要信息，题库按专题和追问链组织，解析与笔记服务于回答过程。

视觉参考了 [豆瓣读书](https://book.douban.com/) 的清晰分类、书架式专题陈列、克制的绿色和可持续阅读的信息密度。参考用于组织原则与视觉节奏，未复制豆瓣页面、书封、标识或图像素材。

曾访问 [iconfont](https://www.iconfont.cn/) 查看图标方向，但其页面未完整展示，当前实现没有使用从该站下载的图标。实际图标使用 [Ant Design Icons Vue](https://github.com/ant-design/ant-design-icons/tree/master/packages/icons-vue)，采用 MIT 许可，由 `AppIcon.vue` 统一映射名称和尺寸。品牌图标与专题封面为本项目的 SVG/CSS 几何图形。

## 信息架构

| 页面 | 用户任务 | 主要操作 |
| --- | --- | --- |
| 学习工作台 | 确认今天的计划和当前状态 | 今日练习、继续会话、浏览专题 |
| 专题题库 | 找到要练的知识点 | 分类、全文搜索、切换专题题/追问链 |
| 练习 | 把知识转化成自己的表达 | 作答、运行代码、看解析、自评、收藏、笔记 |
| 复习清单 | 集中处理薄弱与需要回顾的问题 | 切换薄弱/到期/收藏/笔记，继续练习 |
| 简历对照 | 为项目经历准备可核实的回答依据 | 查看覆盖关系、写证据笔记、进入关联追问 |
| 学习记录 | 查看积累并管理自己的数据 | 每日目标、近期记录、备份导出与恢复 |

全局搜索进入题库结果，支持题干与解析内容匹配。搜索、分类、题型和复习标签以路由参数表示，可返回、刷新和直接分享具体入口。空列表显示原因及下一步入口，学习数据为空时不填入演示统计。

## 视觉语言

核心变量位于 `src/styles/global.css`：

| 用途 | 值 |
| --- | --- |
| 页面背景 | `#f7f9f7` |
| 内容面板 | `#ffffff` |
| 主要文字 | `#263b32` |
| 次要文字 | `#7a867e` |
| 主色 / 主操作 | `#23634c` |
| 选中背景 | `#e9f1e8` |
| 分隔线 | `#e4e9e3` |
| 错误强调 | `#ad4f3b` |
| 面板圆角 | `14px` |

全局正文基准为 16px，采用系统无衬线中文字体；元数据与辅助说明适当缩小。标题通过字重、尺寸与上下间距区分层级。绿用于主操作、导航选中与学习状态；专题封面使用低饱和蓝、绿、紫和陶色，帮助扫描分类。

专题封面由 `TopicCover.vue` 生成，包含书脊、标题、排版符号、几何圆弧和线条。封面服务于专题识别，不依赖外部图片加载；窄屏减少装饰与副标题，保留清晰题名。图标仅作辅助说明，关键操作保留文字或可访问名称。

## 响应式布局

桌面采用固定左侧导航、顶部搜索和内容区。主体最大宽度为 1440px，内容以网格与列表组合，题库可同时比较多个专题。1250px、900px 等断点逐步收紧侧栏和间距。

700px 以下隐藏侧栏，使用底部「工作台、题库、复习、我的」导航与顶部搜索。内容缩为单列或双列专题书架，并预留底部安全区。手机练习页隐藏底部导航，优先展示题目、作答和下一步操作。较长代码在代码区域横向滚动，不撑开整页。

## 交互与状态

- 收藏、笔记、草稿、项目证据和目标都对应真实学习状态，刷新恢复由本机仓储负责。
- 题库中的题卡直接进入所选题目；追问保留原链顺序，帮助理解上下文。
- 客观题保留选项身份；口述自评与参考答案分开。模拟面试先作答，再统一复盘。
- 复习页编辑笔记时，即使暂时清空内容也保留当前输入行，失去焦点后再按列表条件更新。
- 导入备份明确说明替换行为，先选择文件、再确认导入；失败时展示可读错误。
- 安装按钮优先调用浏览器安装事件，不支持时给出对应浏览器操作说明。
- 离线、保存失败与新版本提示有可见文本。应用不显示未实现的登录、同步成功或 AI 评分。
- 同一站点已有编辑窗口时，新窗口显示原因、刷新与导出入口，避免两个窗口相互覆盖记录。

## 可访问性

应用提供跳转到主体的链接、导航区域名称、可见键盘焦点、输入标签、状态消息和图标按钮的可访问名称。当前导航用 `aria-current` 或选中样式表达，收藏使用 `aria-pressed`。搜索框支持 `Ctrl/Cmd + K` 快捷聚焦；系统开启减少动态效果时停用非必要动画与过渡。

可访问性需要持续以真实浏览器检验。新增组件应保持键盘可达、状态不只靠颜色区分、足够的点击区域，并验证长中文标题、200% 缩放与窄屏输入场景。

## 维护约定

新页面优先使用共用的 `panel`、`button`、`tag` 和设计变量；局部布局留在组件的 scoped 样式内。新增图标先加入 `AppIcon.vue` 映射，避免不同页面引入风格不一致的图标集。题目正文与解析以内容可读性为优先，不在产品流程中暴露无助于学习决策的内部实现细节。

设计评价依据是能否快速找到题目、完整阅读解析、顺畅保存自己的回答，并在下次打开时继续练习。装饰元素不应压缩作答区域或遮挡主要操作。
