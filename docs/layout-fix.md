# 模拟入口和 AI 首屏布局修复

本次处理模拟面试入口与说明紧贴、AI 空会话下方大块留白，以及短屏初始页面向外溢出的问题。

## 修改

模拟入口与说明放入独立区域，保留 14px 纵向间距。说明允许自然换行，普通练习不渲染这个区域。

AI 路由使用独立的动态视口布局，清除普通内容页的最小高度约束。手机底部导航参与实际高度分配，不再写死扣除 65px。消息区占满输入区上方的剩余空间，输入区贴合导航或桌面视口底部；没有内容的提示段落不再占高。

长会话、登录注册和题目资料保留各自内部滚动。题内 AI 对话框仍独立占满面板；退出 AI 后其他页面恢复正常整页滚动，没有使用全站 body 滚动锁遮住溢出内容。

## 验证

旧版复现到：模拟入口与说明间距为 0；390×844 的空会话输入区下方约 253px 留白，1440×1000 下约 371px；320/390×568 动态面试首屏外层多出约 71px 可滚范围。

修后独立检查覆盖 Chromium/WebKit、五种视口和七种状态，共 70 个场景。AI 外层高度与视口一致，输入区域底部与导航或面板底部贴合。短屏注册、长对话及长上下文仍能内部滚动，并检查了手机、短屏及桌面截图。

正式回归脚本 `scripts/verify-layout.cjs` 每个引擎包含 30 组检查：模拟入口/普通练习、空会话与焦点和 resize、动态面试、长对话、题内助手、登录注册。Chromium 和 WebKit 的 60 组均通过。生产构建的布局、认证、组合输入、离线及应用更新回归也通过。所有 API 使用夹具，没有真实账号写入和模型调用。

```sh
npm run test:layout
npm run test:layout:webkit
```

报告和截图写入 `test-results/layout/`。生产浏览器回归也包含本脚本，并继续检查认证、组合输入、PWA 离线及应用更新后的记录保留。
